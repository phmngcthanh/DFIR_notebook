# Archived encryption research

Application-level database encryption is deliberately deferred for the lean offline release.

Case files remain ordinary embedded SQLite databases so that recovery, copying, review, and expert exchange stay simple. Investigators must protect the laptop and case directory with BitLocker, FileVault, or an equivalent organization-approved full-device encryption and evidence-handling policy.

There is no case password, account password, authentication service, or authorization layer in the application. The entered expert name is attribution metadata only.

See [README.md](README.md) for the implemented architecture and collaboration workflow.
