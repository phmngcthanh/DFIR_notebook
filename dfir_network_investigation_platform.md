# Archived platform research

This document is retained only as a pointer to an earlier, broader design exploration. It is not the architecture or implementation plan for the current application.

The implemented product is the lean Tauri + React desktop workbench described in [README.md](README.md). It uses one embedded SQLite file and has no daemon, REST API, PostgreSQL, Redis, login system, RBAC, or live collaboration service.

The former proposals for FastAPI/PostgreSQL, tasks, automated log ingestion, YARA, STIX/OpenIOC, attack-path analysis, and PDF reporting are deferred and outside the current MVP.
